## Proof idea
The characteristic polynomial factors as p(x) = (x²−36)(x²+4x+36), with complex roots λ, λ̄ (λ+λ̄ = −4, λλ̄ = 36). Define u by u(0) = 2, u(1) = 28, u(n+2) = −4u(n+1) − 36u(n), so a(2n+1) = u(n)².
- `a6`: since p(x)(x²−4x+36) = q(x²) with q(y) = (y−36)(y²+56y+1296), a satisfies a(n+6) = −20a(n+4) + 720a(n+2) + 46656a(n). This is a linear combination of three instances of the defining recurrence.
- `w_rec`: u(n)² satisfies the same order-3 recurrence. This is a polynomial identity in u(n) and u(n+1).
- `main`: induction over three consecutive odd indices (base values 4 = 2², 784 = 28², 33856 = 184², by rfl).
