## Proof idea
The characteristic roots are 4, −4, 4ω and 4ω², so a(n)/4ⁿ is 6-periodic. Explicitly, a(n) = 2^(2n)·e(n), where e(n) = f(n mod 6) and f = [−1, 1, 2, 1, −1, 4]. Then e(n+4) = −e(n+3) + e(n+1) + e(n), checked case by case on n mod 6. The closed form follows by induction over four consecutive values (`closed`), using the recurrence (`a_rec`, by rfl) and `ring`. For odd index 2n+1 the residue mod 6 is 1, 3 or 5, where e = 1, 1 or 4. So a(2n+1) = (2^(2n+1))² or (2^(2n+2))².
