# OeisA103662.conjecture

- Source: FormalConjectures/OEIS/103662.lean:113 (category research solved), `∃ n, a n = 0`
- Proof idea: take n = 2500. For every b > 1, the number N = b^2500 ≥ 10^5 has a decimal 0. If 10 ∣ b, the units digit is 0. Otherwise use b^4 ≡ 1 mod 16 for odd b (checked over the residues mod 16) and Euler's theorem mod 3125 (φ(5^5) = 2500) for 5 ∤ b, together with 32 ∣ N or 625 ∣ N where it applies. omega then forces digit 1, 3 or 4 of N to be 0, depending on the case. A generic lemma (`P.zero_mem`) says that if ⌊N/10^k⌋ > 0 and ⌊N/10^k⌋ % 10 = 0, then 0 ∈ digits 10 N. So the set of valid bases is empty, sInf ∅ = 0, and a 2500 = 0^2500 = 0.
