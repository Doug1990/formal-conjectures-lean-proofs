# OeisA78590.conjecture

- Source: `FormalConjectures/OEIS/78590.lean:74` (category research solved, question; the answer is "no")
- Statement: `¬ ∀ n : ℕ, 3 ≤ n → a (n - 2) ∣ 2 ^ a (n - 1) + 1`

Proof idea: the statement fails at n = 7. a(5) = 171 = 9·19, and a(6) = (2^171+1)/9 ≡ 3 (mod 18)
(checked by `rfl`, since 2^171 is small enough for the kernel). The order of 2 mod 19 divides 18,
so 2^a(6) + 1 ≡ 2^3 + 1 = 9 (mod 19), and 19, hence 171, does not divide it. The kernel cannot
evaluate 2^a(6) itself. `generalize a (7-1) = b` hides the exponent, and the mod-19 argument
runs for a symbolic b with b % 18 = 3.
