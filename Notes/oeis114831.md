# OeisA114831.conjecture3

- Source: `FormalConjectures/OEIS/114831.lean:79` (category research solved)
- Statement: for a(1)=1, a(2)=2, a(n) = a(n-1) + ⌊2a(n-1)a(n-2)/(a(n-1)+a(n-2))⌋, the ratio a(n+1)/a(n) tends to √3.
- Verified file: `work/oeis114831_a.lean` (this file is an identical copy).

## Proof idea
The rational floor is first turned into natural-number division (`Rat.floor_natCast_div_natCast`), so a(n+3) = a(n+2) + q with q = 2xy div (x+y). Induction gives a(n) ≥ n, so 1/a(n) → 0. Let x = a(n+2) and y = a(n+1). Then a(n+3)/a(n+2) = 1 + q/x, which is within 1/x of f(r) = 1 + 2/(r+1), where r = x/y. Also f(r) − √3 = (1−√3)(r−√3)/(r+1), so |f(r) − √3| ≤ (3/4)|r − √3| (using √3 ≤ 7/4). The error e_n = |r_n − √3| therefore satisfies e_{n+1} ≤ (3/4)e_n + d_n with d_n → 0. A generic lemma (`P.conv`, via e_{N+k} ≤ (3/4)^k e_N + ε/2) gives e_n → 0.
