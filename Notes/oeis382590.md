# OeisA382590.kthPrimeFactor_periodic

- Source: `FormalConjectures/OEIS/382590.lean:113` (category research solved)
- Statement: for every k ≥ 2, the k-th smallest distinct prime factor of a(n) is eventually periodic.

Proof idea (Tao's MathOverflow argument): the identity a(m+4) = a(m+1)·2·(b(m)a(m+3) − a(m+2)b(m+2))
follows from the recurrence by `ring` after unfolding. Together with a(0) = 1, it gives a(n) ∣ a(n+3).
Along each residue class r mod 3, the chain c_m = a(r+3m) satisfies c_m ∣ c_{m+1}. If some c_m is 0,
the chain is 0 from then on, so the value is constant. Otherwise the sorted distinct prime-factor
lists grow by inclusion. A pigeonhole lemma on strictly increasing lists (`idx_le`) shows that once
the (k−1)-th entry exists it stays, and it never increases. A nonincreasing ℕ-sequence is eventually
constant (`anti_stable`, via Nat.find on the minimum). So period 3 works.

Axioms: `propext, Classical.choice, Quot.sound`
