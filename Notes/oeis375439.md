# OeisA375439.conjecture

- Source: FormalConjectures/OEIS/375439.lean:114 (category research solved)
- Statement: for n ≥ 1, a(n) is odd ⟺ n = 3^k or n = 2·3^k.

Proof idea: Truncate the coefficient sequence to a polynomial F over ZMod 3. Then F^3 = expand 3 F
(`ZMod.expand_card`, Frobenius), so conv3 b n ≡ subst3 b n (mod 3) for every b. That gives
rhs = 2·conv3 + subst3 ≡ 0 (mod 3), so the division by 3 in the recurrence is exact. Then
3·a(n) = 2·conv3 + subst3 gives a(n) ≡ subst3 ≡ [3 ∣ n]·a(n/3) (mod 2) for n ≥ 3. Strong
induction from a(1) = a(2) = 1 finishes the proof, using
(n = 3^k ∨ 2·3^k) ⟺ 3 ∣ n ∧ n/3 is of that form, for n ≥ 3.

Axioms: [propext, Classical.choice, Quot.sound]
