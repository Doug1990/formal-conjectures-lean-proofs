- Proof idea: First, integrality: n!·((n+1)!)³ divides 3·(4n)!. This is checked prime by prime with Legendre's formula. For odd p, the termwise Landau inequality ⌊n/q⌋ + 3⌊(n+1)/q⌋ ≤ ⌊4n/q⌋ holds for every q ≥ 4. The only deficit is at q = 3, and the factor 3 covers it. For p = 2 we use v₂(m!) = m − s₂(m) (`sub_one_mul_padicValNat_factorial`) and s₂(4n) = s₂(n). That gives v₂(a(n)) = 3(s₂(n+1) − 1) ≥ 0. So a(n) is odd iff s₂(n+1) = 1, i.e. iff n+1 is a power of 2. The last step is a strong induction on binary digits.
