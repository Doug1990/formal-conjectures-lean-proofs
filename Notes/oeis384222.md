## Proof idea
conjecture_formula reuses the A400194 block lemma (Q.block_len). Each 2-dense block is closed under doubling and halving, so it is {odd elements} × {2^0..2^ν₂(n)}. Its length is therefore (ν₂(n)+1) times the odd count. conjecture_1 has three parts. Positivity holds because splitBy never produces empty blocks. The sum is the length of the flattened list, which is the divisor list, and that list has as many elements as n.divisors. For the palindrome, the generic lemma Q.rev_split says: if r (f y) (f x) = r x y on l, then splitting (l.map f).reverse equals the reversed list of reversed, f-mapped blocks. This is shown via `List.splitBy_eq_iff`. It is applied with f = (n / ·), using (D.map (n/·)).reverse = D (a perm of strictly sorted lists) and n/x ≤ 2(n/y) ⇔ y ≤ 2x for divisors. Taking lengths gives row.reverse = row.
