# Mathoverflow10799.discrete_isoperimetric_inequality

**Proof idea.** Generalise to an arbitrary finite ground set U and a monotone predicate P, and prove p·log(1/p)·I(P) ≥ −m·log m (m = μ_p-measure) by induction on U (`Finset.induction_on`). Removing an element j splits P into the sections P₀ = P and P₁ = P(insert j ·), with measures a ≤ b. Then m = (1−p)a + pb and I = (1−p)I(P₀) + pI(P₁) + (b−a), using `Finset.sum_powerset_insert` and the symmetric-difference identities. The step reduces to the two-point inequality G((1−p)a+pb) ≤ (1−p)G(a) + pG(b) + p·log(1/p)·(b−a), with G = negMulLog. It is 1-homogeneous. Put x = (1−p)a+pb and λ = a/x; then it becomes λ(G(1−p)+G(p)) ≤ G(λ(1−p)) + G(1−λ(1−p)). That follows from `negMulLog_mul`, `negMulLog_nonneg` and one use of `concaveOn_negMulLog`. The final step turns logb into negMulLog/(p·(−log p)).

Axioms: `[propext, Classical.choice, Quot.sound]`
