## Proof idea
First, unfold the well-founded definition once (`a_eq`) to get the two recurrences: `a_odd` (a(2k+1) = a(k)) and `a_even` (a(2k) = a(k) + [k ≥ 2]·a(k−2) for k ≥ 1).
- conjecture1: 2^(n+1)+1 = 2·2^n+1, so it is `a_odd` directly.
- conjecture3: 2^(n+1)−1 = 2(2^n−1)+1. By induction, a(2^n−1) = a(0) = 1.
- conjecture2: the same induction gives a(3·2^n−1) = a(2) = 1.
- conjecture1_value: let c(m) = a(2^(m+1)−2). Then c(0) = c(1) = 1 and c(m+2) = a(2^(m+2)−1) + a(2^(m+2)−3) = 1 + c(m), so c(m) = ⌊(m+2)/2⌋. Then a(2^(n+1)) = a(2^n) + c(n−1), and ⌊(n+1)²/4⌋ = ⌊n²/4⌋ + ⌊(n+1)/2⌋ (shown by a parity split; `t*t` is generalized so that omega can finish).
