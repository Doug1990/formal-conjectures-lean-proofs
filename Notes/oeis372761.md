# OeisA372761.exists_unique_a_eq_prime

- Source: `FormalConjectures/OEIS/372761.lean:94` (category research solved)
- Statement: every odd prime p ∉ {3, 5} equals a(n) for exactly one n ≥ 3.
- Verified file: `work/oeis372761.lean`. `results/oeis372761.lean` is a hand copy of it.

**Proof idea.** Define backward continuants w (u_k = u_{k+1}·k − (k+1)u_{k+2}, with u_{n+1} = 1 and u_n = n+4). The invariant k·u_{k+1} − (k²−1)·u_{k+2} = 5n−4 holds for every k. It comes from the forward continuant of the block 2..k, which equals k. The invariant gives positivity of all u_k, so the `R_next = 0` guards never fire, and cf(n,k) = u_k/u_{k+1}. It also gives u_2 = 5n−4. Chaining the invariant gives (n−1)·u_3 ≡ n!/2 (mod 5n−4), and gcd(n−1, 5n−4) = 1. So a(n) = (5n−4)/gcd(5n−4, n!/2). The number theory part goes as follows. If a(n) = p ≥ 7 and p ≤ n, then p^{v_p(5n−4)} divides n!/2, because e·p ≤ n (the case p = 7, e = 2 is handled by omega). That contradicts a(n) = p. So n < p, and 5n−4 = p·g with g ≤ 4 and g ≡ p⁻¹ (mod 5), which forces n uniquely. Existence takes n = (pc+4)/5 with c ≡ p⁻¹ (mod 5), and then c | 12 | n!/2.
