Proof idea: the sequence has a period-5 block structure. With s = (−1)^k and F the
Fibonacci numbers, a(5k) = s·F(5k), a(5k+1) = a(5k+2) = s·F(5k+1), a(5k+3) = 0 and
a(5k+4) = −s·F(5k+3). `Fb.block` derives the next block (sign flipped) from one block:
it unrolls the order-4 recurrence five times and uses F(n+2) = F(n) + F(n+1), and with
s = ±1 substituted everything is linear, so omega closes it. `Fb.main` runs the induction on k
from the initial values, and the theorem reads off m from n mod 5 (m = 0 when n ≡ 3).

Axioms: propext, Quot.sound.
