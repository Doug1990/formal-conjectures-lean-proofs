# OeisA341254.a_bounds

- Source: `FormalConjectures/OEIS/341254.lean:163` (category research solved)
- Statement: for n ≥ 1, 1/4 < n·r² − a(n) < 3, where r = (2+√5)/2 and a(n) = ⌊r⌊rn⌋⌋.

**Proof idea.** r satisfies r² = 2r + 1/4. Let m = ⌊rn⌋, x = rn − m, A = a(n) = ⌊rm⌋, and t = A − 2m. Because √5 is irrational, rn is not an integer, so 0 < x < 1. The algebra gives rm = 2m + n/4 − εx with ε = r − 2 ∈ (0, 1/8). So t ≤ n/4 − εx < n/4 and t + 1 > n/4 − 1/8. As integers this gives 4t + 1 ≤ n ≤ 4t + 4. Also n·r² − A = 2x + n/4 − t, and 1/4 ≤ n/4 − t ≤ 1 with 0 < 2x < 2 yields both bounds.
