# OeisA91669.prime_and_primitive_root_of_dvd

- Source: FormalConjectures/OEIS/91669.lean:83 (category research solved)
- Statement: for n > 2, n ∣ a(n−1) + 2^(n−2) implies that n is prime and 2 is a primitive root mod n, where a(m) = 2^(m−1)·∏_{k=1}^{m−1}(2^k−1) / m! (ℕ division).

Proof idea: write n = m+1 and P = ∏_{k<m}(2^k−1). (1) Exactness: m! ∣ 2^(m−1)P, so a(m)·m! = 2^(m−1)P. This is checked prime by prime. For p = 2, v₂(m!) ≤ m−1. For odd q, LTE gives q^(1+v_q(j)) ∣ 2^((q−1)j)−1, so q^(t+v_q(t!)) ∣ P with t = ⌊(m−1)/(q−1)⌋, and Legendre gives v_q(m!) = ⌊m/q⌋ + v_q(⌊m/q⌋!) with ⌊m/q⌋ ≤ t. (2) Hence n! ∣ 2^(m−1)(P + m!). (3) If n = q·r with q an odd prime and r ≥ 2, then t ≥ r > ⌊m/q⌋, so q^(v_q(m!)+1) divides 2^(m−1)P and n!. It then divides 2^(m−1)·m!, which contradicts the definition of v_q(m!). (4) If n = 2^k with k ≥ 2, then v₂(n!) = n−1 = m, which forces 2 ∣ P + m!, but P is odd and m! is even. So n is prime. (5) In ZMod p with p = n, Wilson gives (p−1)! = −1. If 2^l = 1 for some 0 < l < p−1, then p ∣ P, so a(m) ≡ 0, so 2^(m−1) ≡ 0, which is impossible. Fermat gives 2^(p−1) = 1. `IsPrimitiveRoot.mk_of_lt` finishes.
