# OeisA397588.conjecture_parity and OeisA397588.three_dvd_a

- Source: FormalConjectures/OEIS/397588.lean:106 and :118 (category research solved)
- Statements: for n ≥ 1, a(n) is odd ⇔ n = 2^k; for n > 1, 3 ∣ a(n). Here a(1)=1 and a(n) = (n+1)·Σ_{k=1}^{n−1} a(k)a(n−k).

Proof idea. Parity: since a(0) = 0, the convolution can be taken over k ∈ [0, n]. Mod 2 the symmetric sum collapses under the involution k ↦ n−k to [n even]·a(n/2)², which equals [n even]·a(n/2). So a(2m) ≡ (2m+1)a(m) ≡ a(m) and a(2m+1) ≡ 0 for m ≥ 1, and strong induction finishes. The P.sym_sum lemma is reused from results/oeis368626.lean. Divisibility by 3 is also strong induction: for n = 2 the prefactor n+1 = 3 does it. For n ≥ 3, every term a(k)a(n−k) with 1 ≤ k ≤ n−1 has an index in [2, n−1] (either k or n−k), so 3 divides it by the induction hypothesis.

Axioms (both): [propext, Classical.choice, Quot.sound]
