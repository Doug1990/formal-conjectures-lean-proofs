# OeisA400194.conjecture

- Source: FormalConjectures/OEIS/400194.lean:85 (category research solved)
- Statement: for n > 0, a(n) = (ν₂(n) + 1) · b(n), where a(n) and b(n) are the maximum number of
  terms and of odd terms in a 2-dense sublist of the divisors of n (`List.splitBy`).

Proof idea: The general lemma Q.G covers any list of blocks with a strictly increasing
flattening and boundary jumps head > 2·last. If x ≤ y ≤ 2x, then x and y lie in the same block.
So every block of the divisor list is closed under d ↦ 2d (when 2d ∣ n) and d ↦ d/2 (when d is
even). Each block (a nodup list) is therefore the image of (its odd elements) × {0..ν₂(n)} under
(o, i) ↦ o·2^i, and this map is injective (via ν₂). That gives length = (ν₂(n)+1) · #odd
for every block. Finally, `foldr max 0` commutes with multiplication by a constant.

Axioms: [propext, Classical.choice, Quot.sound]
