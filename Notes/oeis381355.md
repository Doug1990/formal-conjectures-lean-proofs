# OeisA381355.conjecture

- Source: `FormalConjectures/OEIS/381355.lean:234` (category research solved)
- Statement: for n > 1, prime(n) ∣ a(n), where Σ a(n)xⁿ = xF'(x)/F(x).

Proof idea: Let p = prime(n) > n and H = F^p. (1) For any power series G with constant term 1,
p divides [x^j]G^p for 1 ≤ j < p (binomial expansion of (1 + xR)^p, p ∣ C(p,m) for 0<m<p).
(2) Write F = G + xⁿT with G the truncation below degree n; then [xⁿ]F^p = [xⁿ]G^p + p·f(n),
and the definition f(n) = −([xⁿ]G^p)/p is an exact division by (1), so [xⁿ]H = 0.
(3) x·H' = p·A·H with A = xF'/F (derivative_pow + F·F⁻¹ = 1). Comparing coefficients of xⁿ:
0 = p·Σ_{k≤n} a(k)·h(n−k), h(0)=1, so a(n) = −Σ_{k<n} a(k)·h(n−k), and each h(n−k) with
1 ≤ n−k ≤ n < p is divisible by p by (1).

Axioms: `propext, Classical.choice, Quot.sound`
