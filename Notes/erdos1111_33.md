## Proof idea
Since χ(G) ≥ 8, G is not 2-colourable, so it has an odd closed walk (Mathlib
`two_colorable_iff_forall_loop_even`). Take one, C = (c_0, …, c_k = c_0), of minimal odd length k.
Triangle-freeness gives k ≥ 5. A = support of C has χ ≥ 3 by a parity argument along the walk (TT.par / TT.three_le).
X = N(C), the vertices adjacent to some c_i, contains A. B = V ∖ X is anticomplete to A.
Give each x ∈ X a neighbour index i < k and colour it by the class cl(i) = i mod 2 if i ≤ k−4, and i−k+5 ∈ {2,3,4} otherwise.
If two adjacent x ~ y had the same class with indices a ≤ b, then b − a is even and b − a + 3 < k.
The walk c_a →(along C) c_b → y → x → c_a would then be an odd closed walk shorter than k, which is impossible.
So X is 5-colourable. If B were 2-colourable, G would be 7-colourable, a contradiction. So χ(G[B]) ≥ 3.
No cycle API is needed, only walks (`Walk.drop`/`take`/`getVert`).
