# OeisA307865.a_eq_zero_of_pseudoprime

- Source: `FormalConjectures/OEIS/307865.lean:84` (category research solved)
- Statement: if 2n+1 is an absolute Euler pseudoprime, then no base b satisfies b^n ≡ −1 (mod 2n+1), so a(n) = 0.

**Proof idea.** Let m = 2n+1 = p·q with p = minFac m. Then p and q are odd, and q > 1 because m is composite. Suppose b^n ≡ −1 (mod m).
(i) If p ∣ q, then q² ≡ 0 (mod m). So c = 1+q is a unit with c^n ≡ 1 + nq. By hypothesis this is ±1 mod m. In the case +1, pq ∣ nq gives p ∣ n, which contradicts p ∣ 2n+1. In the case −1, reducing mod p gives 1 ≡ −1, which is impossible for odd p. (In fact this case does not use b.)
(ii) If p ∤ q, CRT gives c ≡ b (mod p) and c ≡ 1 (mod q). Then c is coprime to m, and c^n reduces to −1 mod p and to 1 mod q. Neither +1 nor −1 mod m is compatible with both, because p and q are odd and > 1.

Axioms: `propext, Classical.choice, Quot.sound`
